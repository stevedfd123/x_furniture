X Furniture — website files

The website is responsive and can be viewed on desktop, tablet and mobile browsers. It is a website, not a native Android or iOS app.

To run locally:
1. Extract this ZIP, keeping the assets folder alongside index.html, styles.css and script.js.
2. Open index.html in a modern browser, or run a local web server from this folder:
   python3 -m http.server 4173
   Then visit http://localhost:4173 on that computer.
3. To view it on another device, deploy the files to a web host or serve them on your local network; localhost on a phone refers to the phone itself.

Important: This is a design prototype. The product names, prices, business information and photography are illustrative placeholders. Orders, custom requests and contact forms are not connected to a backend and do not send or save data. Replace the example content, secure permission to use the imagery, and connect real order/contact systems before launching.
